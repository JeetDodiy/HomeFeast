1.2 Executive Problem Statement & High-Impact Value

In urban Indian cities, millions of college students, corporate working professionals, and elderly citizens living away from home struggle to find fresh, wholesome, and hygienic home-style food. 3.1 REST API Route Handlers (App Router /app/api/v1/)

  • GET /api/v1/cooks: Returns nearby verified cooks filtered by city, cuisine, and rating.
  • POST /api/v1/auth: Handles token generation, bcrypt password authentication, and session cookie issuance.
  • POST /api/v1/subscriptions: Creates scoped, multi-day recurring meal plans with explicit cookId locking.
  • GET /api/v1/orders: Fetches active dispatch schedules and customer delivery receipts.
  • POST /api/v1/complaints: Registers customer service tickets directly routed to the Admin Dispute Desk.
  • GET /api/v1/admin/kpis: Aggregates real-time platform metrics across users, GMV, and subscription retention.
